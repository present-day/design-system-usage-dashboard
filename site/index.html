    How it is counted. A scheduled job reads each registered file through Figma's REST API. An instance counts as a library instance when its main component is published by the design system library. A value counts as bound when the node references a variable or style, and as raw when it holds a literal. Values inside an instance are not counted, since they belong to the library.

    What it cannot see. A detached component becomes a plain frame, so detaches are not counted here.
